# October 24 independent audit follow-up: D6

The supplied independent audit reviewed v0.3.9 (8839b73), not v0.3.10.
Its confirmed Windows count defect remained in 0.3.10. MainWindow still used
seven as the total after the catalog grew to nine, hiding bulk installation when
only the original seven tools were present.

0.3.11 derives the displayed total from Rows.Count and the missing count from
the same row collection. The missing-app label, visibility and enabled state
share that value. Packaged self-checks exercise the real window properties in
unshown demo mode for 0/5/7/9 installed tools and an additional tenth row.

The audit's remaining items are hardware uncertainties or optional improvements,
not confirmed defects addressed by this patch. No new hardware coverage or
publisher license grant is claimed. The user-requested official Batch icon and
its existing rights-holder attribution remain in place.
