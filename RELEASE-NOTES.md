# uLEAPP 0.3.10 — Community Preview

- Replaced the generic Batch LEAPP symbol with the official Batch LEAPP application icon on Mac and Windows. Updated artwork attribution and provenance.
- Includes the Batch LEAPP and Map Downloader support introduced in 0.3.9. Map Downloader supports Mac, Windows and Linux. Batch supports Windows (x64 emulation on ARM); Apple silicon Macs have an official manual Download button. No Batch binaries are published for Intel Mac or Linux.
- Mac Batch installation remains manual because the publisher's current build is not notarized and reports version 0.0.0. No security checks are bypassed.

Mac requires macOS 13+; Homebrew is optional. uLEAPP Mac builds are ad hoc signed; Windows builds are unsigned. Linux requires Python 3.10+ and Tk.

SHA256SUMS-0.3.10.txt covers all downloads.
