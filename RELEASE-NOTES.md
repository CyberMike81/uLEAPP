# uLEAPP 0.3.11 — Community Preview

- Fixed Windows installed and missing-app counts after adding Batch LEAPP and Map Downloader. With seven core tools installed, Windows now correctly shows **7 of 9 installed** and offers **Install missing apps (2)**.
- The bulk-install button stays available until every listed app is installed. Counts follow the current tool list, including future additions.
- Added checks against the actual Windows window properties for partial, complete and expanded tool lists.
- Includes the official Batch LEAPP icon and existing companion support. Mac and Linux behavior is unchanged apart from the uLEAPP release version.

Mac Batch installation remains manual; no Batch binaries are published for Intel Mac or Linux. Mac requires macOS 13+; Homebrew is optional. uLEAPP Mac builds are ad hoc signed; Windows builds are unsigned. Linux requires Python 3.10+ and Tk.

SHA256SUMS-0.3.11.txt covers all downloads.
